# Proyecto Web Cloud - Azure & Oracle VM

Este repositorio contiene la estructura de la página principal de Inicio y el servidor web para el despliegue en dos entornos de nube:

1. **Azure Static Web Apps (PaaS):** Despliegue automatizado con el flujo en `.github/workflows/`.
2. **Oracle Cloud Compute VM (IaaS):** Servidor Node.js en `index.js` controlado por el servicio `startwebserver.service`.
